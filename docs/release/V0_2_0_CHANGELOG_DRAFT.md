# RepoSense v0.2.0 Changelog Draft

Draft only. RepoSense remains publicly released as v0.1.0.

## Added

- Evidence-grounded Repository Review Mode.
- Human Review Required queue and review risk matrix.
- Code Health Radar.
- Permission Auditor and AuthZ Matrix.
- Context Pack REVIEW and AI maintenance constraints.
- Studio prioritized Artifact Cards and run status summaries.
- Four-case pinned real-repository smoke harness.
- Queue retry, consumer side-effect, and idempotency evidence correlation.
- TypeORM cross-file import, alias, dependency, and wrapper resolution.

## Improved

- Evidence location validation and strict verification.
- Spring and TypeScript transaction correlation.
- TypeORM operation provenance and transaction coverage calibration.
- Route decorator rejection and NestJS Guard/OpenAPI correlation.
- Queue/cache producer-consumer matching and real-repository coverage.
- Repository Review, Backend Verifier, manifest, and Context Pack wiring.
- Studio run artifact grouping, missing-state semantics, and API privacy.

## Fixed

- Invalid or non-positive Evidence source locations.
- `DeleteDateColumn` and other non-route decorator false positives.
- Demo/smoke scripts modifying tracked archive documentation.
- Installed wheels missing Studio, rulesets, presets, specs, concepts, and
  SQLite initialization schema.
- Studio run APIs returning local absolute path fields.

## Validation

- Canonical Release Demo and Review Demo.
- Manual Chromium Studio visual QA at 1440 x 900.
- Seven real Review screenshots with metadata/privacy checks.
- Pinned validation against NestJS Boilerplate, Spring PetClinic REST,
  Ecommerce Store API, and Spring Kafka Reactive.
- Strict verify, patch exports, run manifest, Demo Gate, and Prod-lite Gate
  calibration.

## Packaging

- Runtime resource resolver for source and installed modes.
- Wheel archive runtime-asset and forbidden-content checks.
- Packaging Gate A dependency-neutral target install.
- Hash-locked six-wheel dependency closure.
- Packaging Gate B fresh-venv offline installation, `pip check`, CLI, Studio,
  Learn, and full artifact-chain smoke.

## Known Limitations

- Static evidence is not a security, authorization, transaction, or
  idempotency proof.
- Gate B is validated for CPython 3.11 on Windows AMD64.
- No pinned real repository contains statically explicit queue retry evidence.
- Spring `SecurityFilterChain` inference is not implemented.
- TypeScript/TypeORM dynamic DI and multi-hop calls can remain unresolved.
- Prod-lite retains a known OpenAPI fixture coverage warning.
- Test ResourceWarnings remain to be cleaned up.
- Wheel archives are not currently bit-for-bit reproducible.
